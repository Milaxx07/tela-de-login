# 🔑 Tela de Login e Cadastro (Interface Front-End)

Uma interface moderna e responsiva de autenticação desenvolvida exclusivamente com tecnologias **Web Vanilla** (HTML5, CSS3 e JavaScript puro). O projeto simula o fluxo completo de cadastro e login de usuários utilizando persistência de dados local no navegador.

---

### 🚀 Funcionalidades

- **Alternância entre Abas:** Navegação fluida e intuitiva entre os formulários de "Entrar" e "Cadastrar".
- **Validação e Simulação de Auth:** Captura de dados em tempo real com mensagens dinâmicas de sucesso e erro.
- **Persistência Local (`localStorage`):** Salva e valida credenciais de usuário sem a necessidade de um banco de dados ativo.
- **Design Responsivo:** Layout adaptável para telas móbiles e desktops com gradiente moderno e foco na experiência do usuário (UX).

---

### 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica de formulários e componentes de entrada.
- **CSS3:** Estilização moderna com **Flexbox**, propriedades customizadas e transições suaves.
- **JavaScript (ES6+):** Manipulação da DOM, tratamento de eventos e gerenciamento do `localStorage`.
